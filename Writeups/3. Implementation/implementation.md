## Report Detail

I will be developing the final solution module by module based, using iteration for each module and create multiple versions until it is perfected. I will review each module with my clients to ensure they are satisfied with how it turns out and ask them for any feedback if they have any.

To develop the solution, I am using Visual Studio Code to write and execute my code. 

I will be separating the modules so they each have their own individual file, making it easier for me to read different modules of code in different files rather than the entire code being in one.

I will also be git so I can keep track of all the changes that I make to my file, and review them after each change has been deployed. Also, if at any point there is a bug in my code which I am unable to resolve, I can review the past changes made and retrieve that code, creating redundancy. 

This will also help me see an overview of the development cycle, being able to see what code was produced when and what changes were made at what times.
